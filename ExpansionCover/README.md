This requires an Oxocard Connect and an Expansion Cartridge.
You may grap your version in Switzerland hat www.oxocard.ch, in Germany at https://shop.heise.de/shop-aktionen/aktionen/oxocard/ and in the USA at https://www.makershed.com/products/make-oxocard-innovator-kit


Steps:
- Connect the OXOCARD with your WIFI
- open the browser and type editor.nanopy.io. 
- On the OXOCARD, open "pairing" to create pin which need to typed in in the browser.
- choose any of the games on the samples section.
- You may run it immediately.
- If you want to burn it to the expansion cartridge, there are only two steps ahead:
- Plug in the card and select the game
- In the contect menu, choose "Load on cartridge" and wait a bit.


When ejecting the reentering the cartridge, the game immediatly starts, like on older game consoles!
